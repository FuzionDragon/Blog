### Page Writer Development

It was long overdue to be worked on as a result of my studies taking up most of my free time so I couldn't work on it as I wished. The notable feature that was worked on was the data synchronisation system, for both the network component and the database component. The networking was quite daunting as I needed to relearn TCP and the eventually UDP protocols, as I wanted to make a rudimentary replica of the LocalSend protocol (an excellent tool that I use lot). It took a couple weeks but I got it, creating a solution which could send a copy of the respective database files to the device looking to be synced with. Part of the issues were regarding the Android filesystem not having a dedicated temp directory, something I assumed it would have as it is originally based on Linux. This caused an issue which took lots of diagnosing (didn't help that I forgot some error handling which could have caught the panic caused by the lack of a temp directory on Android), which turned out to be quite simple to resolve. 

Then there is the database synchronisation. This required an overhaul to a lot of the database related functions as I had to eventually change the schema for the Snippets table to contain a last_modified value, which is another minor hiccup during development. A lot of the issues that caused this aspect to be quite a pain to work with was, once again, Android filesystem related misunderstandings. I won't go into too much detail but the general gist is that some of the problems related to certain paths not being specified well enough or me misunderstanding how certain functions in Rust worked (which seemed to work fine before). There was hesitation to add the whole last_modified value to Snippets as I knew it would be a pain to tweak every affected function, but I bit the bullet when I realised that there wasn't a better solution to preserve the notes in a way I wanted.

With all those problems out of the way, the feature worked quite well (although not without its kinks) and with some additions to its buttons like a double-click to confirm prompt to ensure the user won't accidentally use it the project is in a decent state at the moment. There are some things like manual saves (which could open up the ability to have multiple databases of notes) and other tweaks and additions but overall Page Writer is very much usable and I might go back to using it regularly again.
